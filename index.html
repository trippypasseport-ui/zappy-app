Paiement Stripe
Les paiements des abonnements commerçants passent par Stripe. Pour des raisons de sécurité, la clé secrète Stripe ne se configure pas depuis cet écran (elle ne doit jamais transiter par l'app ni par une base de données lisible) : elle est ajoutée directement dans l'espace sécurisé du serveur, en dehors de l'application.

Quand le compte Stripe est prêt, transmets-le pour l'activation finale — webhook à renseigner dans Stripe :
